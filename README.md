# Ramleela - Ruby Park

An ancient Ayodhya / Ramayana heritage-themed web experience crafted for the celebration of **Ramleela - Ruby Park**.

Built and powered with devotion by **Base2Ace Technologies**.

---

## 🌟 Features

1. **Ancient Ayodhya Aesthetics**:
   - Golden Vedic temple aesthetic, sandstone borders, sacred saffron gradients, and subtle particle embers.
   - Distinctive typography using *Rozha One*, *Yatra One*, *Cinzel Decorative*, and *Outfit*.
   - Vedic top ticker with sacred shlokas (*Mangal Bhavan Amangal Hari*).

2. **Video Pavilion**:
   - Streaming video player with custom golden play controls.
   - **Fullscreen Cinema Mode**: Press `F` or click the Fullscreen button for full viewport view.
   - **Theater Mode**: Press `T` to dim background ambient elements.
   - Keyboard shortcuts: `Space` (Play/Pause), `F` (Fullscreen), `T` (Theater Mode), `Esc` (Exit).

3. **Audio Experience**:
   - Real-time synthesized temple bell chime generated using the Web Audio API without external audio files.

4. **Preserved Gallery Infrastructure**:
   - Includes full HTML5 image card layouts and a Lightbox modal ready for photos.

---

## 🚀 Running Locally

To run the local server with HTTP 206 range-request video streaming:

```bash
python server.py 8899
```

Then visit [http://localhost:8899/index.html](http://localhost:8899/index.html).
